# Marketplace

Учебный маркетплейс на **Next.js** и **Tailwind CSS**: здесь можно отрабатывать вёрстку, компоненты RSC на живых сценариях — каталог, карточка товара, профиль и общий каркас сайта. Проект задуман как песочница, а не как production-продукт: можно экспериментировать с сетками, типографикой, состояниями и адаптивом без лишней бизнес-логики.

Стек: React 19, Next.js 16, Tailwind CSS 4, TypeScript. Запуск: `pnpm dev` — приложение откроется на [http://localhost:3000](http://localhost:3000).
